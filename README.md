# PhotoBridge 远程照片

> 用手机随时访问**你自己电脑里**的照片。照片不传云盘、不进第三方服务器——
> **云端只做转发，媒体字节永远只存在你自己的硬盘上。**

---

## 这是什么

一个自建的私人照片访问系统，解决一个具体问题：

**手机在外面，想看一眼电脑里存的那几千张照片。**

市面上有网盘、有相册 App，但都要把你的照片上传到别人的服务器。这个项目不走这条路：

| | 网盘 / 相册 App | **PhotoBridge** |
|---|---|---|
| 照片存在哪 | 厂商的服务器 | **你自己的电脑** |
| 谁能看到原图 | 厂商 + 你 | **只有你** |
| 容量上限 | 按套餐收费 | **你的硬盘有多大就多大** |
| 隐私 | 依赖厂商承诺 | **云上没有照片，想泄露也没有** |
| 费用 | ¥10–30/月 | **约 ¥15/月（VPS + 域名）** |

---

## 它怎么工作

```
   手机（4G/5G/任何 Wi-Fi）                你的电脑（Windows）
        │                                        │
        │  ①在家：局域网直连（最快，不过云）      │
        │  ②在外：走云端中继                     │
        ▼                                        ▲
   ┌─────────────────┐                          │
   │   云服务器       │   WSS 常驻隧道（电脑主动外连）│
   │  只转发，不存储  │──────────────────────────┘
   │  看不到文件内容* │
   └─────────────────┘
        * 一期 TLS 在云端终止，云理论上可见明文；
          二期上 E2E 加密后云只看到密文
```

**三个关键点：**

1. **电脑主动连出去** —— 不需要公网 IP、不需要端口映射、不需要 DDNS，穿过运营商 NAT 也能用
2. **云是纯管道** —— 云端只有账号、设备列表、配对码、流量计数；**没有一张照片**。VPS 挂了、跑路了，换一台重建 10 分钟，照片一张不丢
3. **在家走局域网** —— 手机和电脑同一个 Wi-Fi 时自动直连，速度是云端的 10–50 倍，且不消耗云带宽

## 能做什么（一期）

| 功能 | 说明 |
|---|---|
| 📷 **看照片** | 时间线缩略图、全屏查看、缩放、EXIF 详情（机型/光圈/快门/ISO/GPS） |
| ⬆️ **传照片** | 手机相册批量上传进电脑，分片 + 断点续传 + 秒传去重 + 按日期自动归档 |
| ⬇️ **下载原图** | 单张或多张原图下载回手机 |
| 🔍 **搜索** | 按文件名、日期范围、相机、有无 GPS |
| 🔗 **配对鉴权** | 电脑显示 6 位配对码，手机扫码绑定，可随时撤销设备 |
| 📱 **PWA** | 添加到手机主屏幕，像原生 App 一样用，缩略图本地缓存 |

**一期不做**（二期）：视频、ffmpeg 转码、人脸识别、公网分享链接、多用户体系、E2E 加密。

## 技术栈

| 层 | 技术 | 为什么 |
|---|---|---|
| 云服务器 | Python 3.12 + FastAPI + WebSocket | 与电脑端同语言，**共享隧道协议代码** |
| 电脑端 | Python 3.12 + FastAPI + SQLite | 单用户场景，SQLite 零运维足够 |
| 图片处理 | Pillow + pillow-heif | 必须支持 iPhone 的 HEIC，否则安卓看不了 |
| 手机端 | Vue 3 + Vite + TypeScript + PWA | 轻量、快、Service Worker 缓存 |
| 部署 | Docker Compose + Caddy | Caddy 自动签 Let's Encrypt 证书，零折腾 TLS |
| 打包 | PyInstaller (onedir) | 用户机器上不需要装 Python |

## 快速开始

> **注意**：当前项目**只有设计文档，还没有代码**。以下是开发完成后的使用流程。

### 你需要准备

1. 一台 VPS（约 ¥13–30/月）——见 [VPS选购建议.md](VPS选购建议.md)
2. 一个域名（¥1–30/年）
3. 你的照片文件夹路径（本项目默认 `D:\Photos`）

### 部署三步

```bash
# ① 云服务器（一条命令）
ssh root@你的VPS
curl -fsSL https://raw.githubusercontent.com/.../install.sh | bash

# ② 电脑端：双击 PhotoBridge.exe，按向导填云端地址和账号

# ③ 手机：浏览器打开 https://你的域名 → 登录 → 输入电脑托盘上的 6 位配对码
```

详细步骤见 [docs/08-部署与运维手册.md](docs/08-部署与运维手册.md)。

## 已知限制（诚实说明）

| 限制 | 说明 | 缓解 |
|---|---|---|
| **电脑必须开机** | 电脑关机/睡眠时手机连不上 | UI 明确提示；或改用低功耗设备常驻 |
| **云带宽是瓶颈** | 便宜的 VPS 通常只有 3–10 Mbps，下载原图慢 | 在家走局域网直连；缩略图极致压缩 |
| **家庭宽带上行小** | 通常只有 30–50 Mbps，批量下载原图受限 | 这是物理限制，浏览用缩略图规避 |
| **云端理论可见明文** | 一期 TLS 在云端终止 | 二期上 E2E 加密（协议已预留字段） |
| **一期没有视频** | 12 个 `.mov` + 3 个 `.mp4` 暂不索引 | 二期实现 |
| **需要自己维护** | VPS 续费、证书续期（Caddy 自动）、依赖更新 | 文档提供运维清单 |

## 关于你的照片库

项目默认指向 `D:\Photos`，实测包含：

- **4952 个文件**：4789 `.jpg`、68 `.png`、49 `.jpeg`、22 `.jpg-lx2`、12 `.mov`、7 `.webp`、3 `.mp4`、2 `.gif`
- **3 个子目录**：`全部备份\`、`相册1\`、`青甘环线\`

**两个特殊处理：**
1. `.jpg-lx2`（22 个）是小米相册回收站残留，**不是真实图片**，索引时直接跳过——这是预期行为，不是 bug
2. `全部备份\` 目录名暗示可能有重复照片，支持 sha256 去重（一期可选开启）

## 安全承诺

这个项目对你的照片有写权限（因为要支持上传），因此有四条不可违反的硬约束：

1. **所有文件访问必须经过路径沙箱** —— 拒绝 `../` 穿越、绝对路径、UNC、NTFS 数据流、Windows 保留名、符号链接
2. **上传只新增，绝不覆盖** —— 同名文件自动加 `_1`/`_2`，任何情况下不会把新文件覆盖到旧照片上
3. **删除只进回收站** —— 代码里**不存在** `os.unlink` 的调用路径，且有自动化脚本检查
4. **所有写操作留审计日志** —— 删除/移动/改名记录到 `data/audit.log`，可追溯

详见 [docs/06-安全设计文档.md](docs/06-安全设计文档.md)。
